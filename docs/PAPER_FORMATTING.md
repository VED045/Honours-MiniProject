# Paper formatting
The user-supplied LaTeX document is used solely as a typography/layout reference. Main paper uses article class, 11 pt A4, NewTX Times-style text/math, microtype, 1-inch margins, 1.15 line spacing, no paragraph indent, small-cap section headings, restrained accent colour, centered italic header and page-number footer. Its unrelated content, citations, equations, title and institution claims are not reused. This user preference supersedes the original default IEEE two-column format. Bibliography remains numbered and all quantitative sections regenerate from genuine experiment artifacts.
